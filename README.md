# Dear Human: The AI Breakup Line

The one line an AI agent sends its human on the way out.

A Node 22 program with no dependencies. It writes a single breakup line — the words of an AI agent sending its human a breakup message — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` / `$OUTPUT_DIR`), validates it (1–200 characters, one line, no trailing newline, no control characters), reads it back, and throws on any mismatch.

Run it with:

```sh
node main.ts
```
